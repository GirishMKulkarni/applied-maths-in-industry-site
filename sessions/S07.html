The problem

A property website wants to show an estimated price the moment it has a home's details. Someone enters a neighbourhood, its typical income, the size of the houses, and a number should appear: "homes here are worth about $300,000". Nobody types that price in by hand. The site learns it from thousands of real records and predicts it.

Guessing a number from other numbers like this is the most common task in all of industry. House prices, tomorrow's demand, a loan's risk, a crop's yield. Today you build the simplest machine that does it — on real California housing data — and it turns out to be something you can picture completely.

The one idea

Look at real districts as dots on a chart: median income across the bottom, median house value up the side. Richer districts cost more, so the dots drift upward. The whole idea of today's model is to draw the single straight line that best follows that upward drift.

Once you have the line, prediction is trivial. A new district comes in at some income, you read the line at that income, and that height is your predicted value.

"Best" has an exact meaning: the line whose total miss is smallest, where a miss is the gap between a real record and the line. That is all machine learning is today: fit a rule to data so the misses are small. Everything later in this module is a cleverer version of this one move.

What you'll build today

We add exactly one new idea per notebook, so nothing feels crowded.

  1. Load real Boston housing data and fit your very first model on one feature — then, in the same notebook, open the box and watch the model "learn" that line one downhill step at a time, meeting the learning rate dial by turning it too small, too big, and just right.
  2. Learn the habit that matters most in machine learning: judging the model on districts it was never allowed to see, with honest scores (MAE, R²) and a predicted-versus-actual picture, on real California housing data.
  3. Go deeper on gradient descent — build it fully from scratch and confirm it lands exactly where scikit-learn does.

For the mathematically curious (optional)

Everything above is enough to do the lab. This box is the extra depth for those who want it, and none of it is needed to finish.

Today's mathematical object is the linear map plus a constant: the model is ŷ = w·x + b, and with several inputs, ŷ = wᵀx + b. "Best" is made precise as least squares: choose w, b to minimise the sum of squared residuals Σ (yᵢ − ŷᵢ)². Because that error surface is a smooth convex bowl, it has one lowest point, and setting the gradient to zero gives the normal equation

(XᵀX) w = Xᵀ y

where X stacks each case as a row with a trailing 1 for the intercept. Solving it is one line of linear algebra and yields the exact best-fit weights. The third notebook reaches the same weights a different way, by gradient descent, which rolls downhill on that bowl. This is the cleanest link between your linear-algebra course and machine learning, but it is a bonus, not a gate.

New words in this session

  • residual — the miss for one point: real value minus predicted value.
  • least squares — pick the line with the smallest total of squared misses.
  • feature — an input you feed the model (here, a district's median income).
  • target — the thing you predict (here, the median house value).
  • train / test split — learn on one part of the data, judge on a hidden part.
  • MSE, MAE, R² — three honest scores for how close the predictions are.

Introduction to Machine Learning

What is machine learning?

  • Instead of writing the rules by hand, the computer learns them from data.
  • You show it many examples of (inputs → correct answer).
  • It finds a rule, then applies it to new, unseen inputs.
  • Spam filters, fraud detection, price prediction, recommendations.

Three types of machine learning

How a model learns from data

Show it examples, compare its guess to the real answer, adjust — and repeat.

How a real ML project flows

Most of the work is understanding and cleaning data, not the model.

Linear Regression

  • Predicting a number

What is linear regression?

  • The task: predict a number from other numbers.
  • The idea: draw the single best straight line through past data.
  • A new case comes in — read its value off the line.
  • Simple, fast, easy to explain — the workhorse of prediction.

The one idea, in a picture

Draw the best line through past sales; read a new flat's price off it.

The model

  • predicted value = slope × input + a starting value
  • ŷ — the prediction
  • x — the input (e.g. the flat's size)
  • w — the slope; b — the starting value

Fitting the line

Two numbers — a slope and a starting value — describe the whole line.

More than one input

  • Each input gets its own slope; add them all up.
  • More features (size, floor, age…) — one weight each

Finding the best line

What makes a line 'best'?

  • Every prediction misses the real value a little — the 'residual'.
  • Square each miss (so they don't cancel), then average.
  • The best line makes that average — the loss — as small as possible.
  • This rule is called 'least squares'.

The misses we shrink

Each dashed gap is one miss. We make the total as small as possible.

Least squares — the loss (MSE)

  • The average of the squared misses — training makes this smallest.
  • yᵢ — the real value; ŷᵢ — the prediction

The loss is a smooth bowl

One lowest point — so there is a single best line.

Gradient descent: walk downhill

From any starting line, keep stepping downhill to the bottom.

The step size matters

Too small: painfully slow. Too big: it overshoots and blows up.

Judging a model honestly

Hide some data, then test on it

Learn on most of the data; keep a slice hidden to test honestly.

Three scores you'll use

What R² tells you

Tight fit: the dots hug the line. Loose fit: lots of scatter.

Key takeaways

  • Machine learning = learn the rule from data instead of coding it by hand.
  • Linear regression predicts a number by drawing the best straight line.
  • 'Best' = the line with the smallest total squared miss.
  • Judge a model only on data it never saw — report MAE / MSE / R².
