Module 0 — Industry Toolkit & Math-to-Code Bridge

S01 · Python Basics for Math Students

Math object todayFunctions, sequences and sets — the objects you know, now written in code.

Overview

This is the very first session of the course, and the first time most of you will write code. That is exactly the right place to be: you already own the hard part, the mathematics. We are simply adding a tool that lets you put that mathematics to work.

The big idea of the day is that programming is not a new way of thinking for a mathematician. A function in code has a domain, a rule and an output, just like the functions you have studied for years. A Python list is a finite sequence a₀, a₁, a₂, …. A Python set is a set: no duplicates, no order, with union and intersection. Once you see Python as a new notation for objects you already know, the fear melts away.

We will not invent anything mathematically difficult today. Instead we take four algorithms you already understand — Fibonacci numbers, Euclid's GCD, the Sieve of Eratosthenes, and Newton–Raphson — and write each one in Python. Because the maths is familiar, you can spend all of your attention on the code.

What you'll do in the lab

  1. Take your first steps: name values with variables, meet the basic types, choose a path with if/else, repeat work with a for loop, and define your own function — then connect that function back to a maths mapping x ↦ f(x).
  2. Write the Fibonacci sequence with a simple loop, then write Euclid's GCD, and check both against small examples you can verify by hand.
  3. Build the Sieve of Eratosthenes from a list of True/False flags and print every prime up to 50.
  4. Write a Newton–Raphson root finder for f(x) = x² − 2, watch the sequence converge to √2, and compare with math.sqrt.

By the end you can

  • Name values with variables, recognise the basic types (int, float, str, bool), and print results.
  • Choose between paths with if/else and repeat work with a for loop.
  • Define and call your own function, and see it as a mapping from inputs to one output.
  • Implement four classic algorithms from scratch and test each on inputs you can check.
