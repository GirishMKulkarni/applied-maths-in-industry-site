S09 · Three Ways to Classify — Logistic Regression, KNN and SVM

The problem

A bank is about to approve a loan. Before it releases the money it wants one answer: will this borrower repay, or default? A payments company watching a UPI transaction wants the same kind of answer in a fraction of a second: is this genuine, or fraud? A telecom looking at a customer's last few months wants to know: will they leave for another network next month, or stay?

Every one of these is a yes-or-no question answered from data. Last time you predicted a number, like a flat's price. Today you predict a category. This is the other half of everyday machine learning, and it powers a huge share of what banks, payment apps and shops actually run in production.

The one idea

Picture the past cases as coloured dots. Borrowers who repaid in blue, those who defaulted in red, spread out by whatever we measured about them. A classifier draws a boundary that separates the two colours as cleanly as it can. For a new case we see which side of the boundary it falls on, and that is our answer.

There are three classic ways to draw that boundary, and today you build all three on the same data:

  1. Logistic regression — the linear model you already know, plus a sigmoid curve that turns its score into a probability between 0 and 1. Straight boundary, fast, and it tells you how sure it is.
  2. KNN (k-nearest neighbours) — a lazy learner. It stores the training cases and classifies a new case by a majority vote of the k stored cases nearest to it. No training at all; the boundary is whatever the data says.
  3. SVM (support vector machine) — it places the boundary to leave the widest empty "street" between the classes, using only the borderline cases (the support vectors) that sit on the street's edge. With the RBF kernel that boundary can bend into a smooth curve.

Same job, three different approaches, and the honest message of the day: no single classifier is best. The shape of the data decides — a straight line is plenty when the groups are neatly separated, and curved boundaries win when they are not. Which brings the real lesson: how do you judge any of them honestly?

There is a catch, and it is the second half of today. When "yes" is rare, and in fraud or disease it always is, plain accuracy becomes a liar. A model that lazily says "no" to everything can be right 95% of the time and still catch zero fraud. So you will judge a classifier the way industry does: the confusion matrix, precision, recall, F1 and ROC-AUC — and you will move the threshold to trade catching more cases against raising fewer false alarms.

What you'll build today

For the mathematically curious (optional)

Everything above is enough to do the lab. This box is the extra depth for those who want it, and none of it is needed to finish.

Logistic regression first computes the same linear score you met in regression, z = wᵀx + b, then passes it through the sigmoid σ(z) = 1 / (1 + e^(−z)), which squashes any real number into the interval (0, 1). That output is read as a conditional probability, P(class = 1 | x): the chance the label is 1 given what we observed. The decision boundary is the set of points where z = 0, so σ(z) = 0.5; because z is linear in x, that frontier is a straight line (a flat plane in higher dimensions). Training does not use squared error. It uses cross-entropy, also called log-loss: for each case take the probability the model gave the correct answer and score it as −log(that probability), then average. A confident correct answer costs almost nothing; a confident wrong answer costs a lot. This comes straight from maximum likelihood: minimising cross-entropy is the same as maximising the probability of the labels we actually observed. The Stretch cell in the first notebook shows the sigmoid and the log-loss computed by hand, matching what scikit-learn does for you.

KNN is defined by a distance and a vote. The default distance is the Euclidean distance, d(x, x′) = √(Σ(xᵢ − xᵢ′)²), the straight-line distance you know from the Pythagorean theorem. For a new point, take the k stored points with the smallest distance and let them vote; the majority class wins. Because distance adds up contributions from every feature, a feature with a large range silently dominates — which is why KNN (like SVM) demands feature scaling, usually a StandardScaler that gives every feature mean 0 and variance 1. Training is effectively nil; the cost is paid at prediction time, when the new point must be compared with every stored point.

SVM chooses the boundary with the largest margin — the widest empty strip between the classes. If the hyperplane is w·x + b = 0, the margin width is 2 / ‖w‖, so training minimises ½‖w‖² subject to every point being on the correct side (allowing soft margins controlled by the cost C). Only the support vectors — the points exactly on the margin edge — constrain the solution, so moving any other point leaves the boundary unchanged. The kernel trick makes the boundary bend: the RBF kernel K(x, x′) = exp(−γ‖x − x′‖²) corresponds to mapping the points into a higher dimension where they are linearly separable, without ever computing that map explicitly. C and γ are the two knobs you tune.

New words in this session

  • classifier — a model that sorts each case into one of a few categories.
  • logistic regression — the classic classifier: a linear score squashed into a probability.
  • sigmoid — the S-shaped curve that turns any number into a value between 0 and 1.
  • decision boundary — the frontier where the model switches its vote from one class to the other.
  • KNN (k-nearest neighbours) — a classifier that labels a new case by a majority vote of the k stored cases closest to it; it does no real training.
  • Euclidean distance — the straight-line distance between two points.
  • SVM (support vector machine) — a classifier that places the boundary to leave the widest gap (margin) between the two classes.
  • support vector — one of the borderline cases sitting on the edge of that gap; only these points decide where the SVM boundary goes.
  • kernel — a trick that lets an SVM bend its boundary into a curve (e.g. the RBF kernel) instead of a straight line.
  • feature scaling — putting every feature on a comparable scale (e.g. with a StandardScaler) so no single large-range column dominates a distance; KNN and SVM need it.
  • confusion matrix — the table of the four counts: right and wrong, for each class.
  • precision / recall — of the cases we flagged, how many were real; and of the real ones, how many we caught.
  • ROC-AUC — one number for how well the model ranks real positives above the rest; 1.0 is perfect, 0.5 is guessing.
  • threshold — the cut-off probability at which we decide to call a case "yes".

Full definitions are in the glossary.
