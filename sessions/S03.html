S03 · Spreadsheets You Drive with Code (Pandas & Excel)

New here? Start with these

Short, picture-first notes for anything below that is unfamiliar. Ten minutes each is plenty. You do not need a maths or a coding background to follow this session.

  • Python in 15 minutes
  • Glossary

The problem

A shop owner in Pune keeps a year of sales in an Excel file: every order, across a few city outlets, with customer names and amounts in rupees. Someone in the team emailed her the file. Before the month-end review she wants three things from it: which city sold the most, which customers are the big spenders, and a clean copy with the blanks, the repeated row, and the one column that came in as text all sorted out. Doing that by scrolling and clicking in the spreadsheet takes an afternoon, and she will still miss something.

The one idea

A DataFrame is a spreadsheet you drive with code. It has the same rows and columns you would see in Excel, but instead of clicking, dragging and copying formulas, you type one short instruction and the whole table answers. "Keep only the Mumbai rows." "Total the sales for each city." "Glue the loyalty-tier sheet onto this one." Each of those is a single line, and it runs exactly the same way on five rows or on five lakh.

Once you can say what you want in that short language, the shop owner's afternoon of scrolling becomes a handful of lines that run in a blink and never miss a row.

What you'll build today

  1. Read the shop's sales file (data/shop_sales.csv) off disk, look at it (shape, info), pull out the parts you want, and keep only the rows that pass a yes/no test.
  2. Total and count the sales for each city and customer (split-apply-combine), then join a sheet of loyalty tiers onto it and summarise the result.
  3. Read a real, messy multi-sheet Excel workbook (data/shop_sales_messy.xlsx), stack its regional sheets, and clean it end to end: blanks, a duplicate row, fake "missing" codes, and a price column that arrived as text with commas.

You don't need to already know

We teach all of this from scratch today, in small steps:

  • what a table (a DataFrame) is, and how to select, filter, group and join it,
  • how to read and write a real Excel file from Python,
  • the standard steps for cleaning real, messy data.

The little we assume: how to run a notebook cell, and how to read a small table. Both are quick to pick up.

If you already live in Excel — pivot tables, VLOOKUP, filters — you have the instincts for all of this already. This session hands those instincts a keyboard, and the notebooks have cells marked Stretch (optional) for you.

By the end you can

  • Read a real file into a table, describe it as rows of records with named columns, and look before you compute (.head(), .shape, .info()).
  • Select parts of a table by name (.loc) and by position (.iloc), and keep only the rows that pass a True/False test.
  • Total and count with groupby (split-apply-combine), and join two tables on a shared column with merge.
  • Read and write Excel files, and run the standard cleaning steps (blanks, duplicates, wrong types) on messy data.

For the mathematically curious (optional)

Everything above is enough to do the lab. This box is a bonus for anyone who enjoys seeing the structure underneath, and none of it is needed to finish.

The tidy name for today's table is a relation. Think of the set of every possible (customer, city, units, price) combination; the actual rows in your table are a chosen subset of that. Each row is a tuple, and the column names are its coordinates, its named fields. The row labels down the left are the index, an indexed set that addresses the rows the way keys address values in a dictionary.

Seen this way, the operations stop looking like a bag of commands. Filtering with a mask picks out a sub-relation. groupby splits the relation into blocks that share a key and summarises each block. A merge combines two relations on a shared attribute. It is the same set theory you may have met in a first algebra course, now with a keyboard. But it is a nice picture, not a gate: you can do every lab today without thinking about it once.

New words in this session

  • DataFrame — a table in Python: rows and columns, like a spreadsheet you drive with code.
  • Series — a single column of a DataFrame, carrying its row labels.
  • index — the row labels down the left of a table; the address of each row.
  • .loc / .iloc — pick rows and columns by name (.loc) or by position (.iloc).
  • boolean mask — a column of True/False that keeps only the rows you want.
  • groupby (split-apply-combine) — split rows into groups, apply a summary to each, combine the answers into a small table.
  • merge (join) — glue two tables together by matching a shared key column.
  • NaN — pandas' marker for a missing or blank value.
