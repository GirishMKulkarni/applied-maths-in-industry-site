About this course

Applications of Mathematics in Industry is a 60-hour course (30 two-hour sessions) that turns mathematics students into applied problem-solvers for industry. Every session opens with the mathematical object it exercises, then puts that mathematics to work in code on a realistic problem.

How to use this site

  • Open a session, read the overview, then open its notebooks in Colab to follow along.
  • Sessions appear here after they are taught in class.
  • All code is plain and heavily commented — it assumes you are new to programming.

Setup on your own machine (optional)

Colab needs no setup. To run locally we use uv:

uv venv
uv pip install -r requirements.txt
uv run jupyter lab
