About this course

Applications of Mathematics in Industry is a 60-hour course (30 two-hour sessions) that turns strong problem-solvers into people industry pays for. It is built for a mixed class: mathematics, commerce, economics, computer science, engineering, statistics, and people new to both code and maths. You do not need to be a programmer to start, and you do not need a mathematics degree to keep up.

How every session works

Each session opens with a real industry problem and the one plain idea that solves it, then builds the code step by step. The formal mathematics is always there for those who want it, kept as an optional "go deeper" section rather than a gate.

How to use this site

  • New here? Begin with Session 0 — a welcome, a short self-check, and how the material is layered.
  • Open a session, read the overview, then open its notebooks in Colab to follow along. If a word or idea is new, open the matching primer.
  • Sessions appear here after they are taught in class.

Setup on your own machine (optional)

Colab needs no setup. To run locally we use uv:

uv venv
uv pip install -r requirements.txt
uv run jupyter lab
