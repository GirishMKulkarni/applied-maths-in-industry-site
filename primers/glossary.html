Glossary

Plain-English meaning of the technical words in the course. When a word is new, look it up here. Each session also lists its own "new words" at the foot of its README, and the notebooks gloss terms in plain English right where they appear.

Words are listed A to Z.

(s, S) policy

a restock rule: when stock falls to s, order back up to S.

.loc / .iloc

pick rows and columns by name (.loc) or by position (.iloc).

A/B test

ship the old version to half your users and the new one to the other half, then compare, to see if the change really helped.

ACET

the Actuarial Common Entrance Test, the entry exam to the Institute of Actuaries of India.

activation

the "bend" (like ReLU) that lets a network fit curves, not just straight lines.

actuary

a professional who measures and prices long-term financial risk (insurance, pensions), qualifying through a series of exams.

aggregate

a summary of many rows into one number, like a sum or a count.

AR / MA

today as a weighted sum of recent values (AR) or recent surprises (MA).

ARIMA

a forecasting model that combines AR, differencing, and MA.

array

A list of numbers that the numpy library can do fast maths on all at once, for example finding the average of a thousand numbers in one step.

assert

a line that checks a belief and stops loudly if it is false.

assignment problem

match each worker to exactly one task at least total cost.

assumption

a simplification you chose, written down so it can be argued with and tested.

backpropagation

working out how to nudge each weight; it is the chain rule, run automatically.

backtest

replay a trading rule over past prices to see what it would have earned.

bagging / Random Forest

grow many trees on random samples and let them vote.

BFSI

Banking, Financial Services and Insurance, the sector most quant and actuarial jobs sit in.

bias audit

checking whether a model treats groups of people differently.

binary variable

a decision that can only be 0 or 1, a yes/no switch.

BLUF (bottom line up front)

lead with the recommendation, then justify it.

boolean mask

a column of True/False that keeps only the rows you want.

boosting / XGBoost

grow trees in sequence, each fixing the last one's mistakes.

branch

a parallel line of history for trying something without risk.

broadcasting

NumPy stretching a smaller array to fit a bigger one so they combine without a loop.

caching (st.cache_resource)

load the model once and reuse it, instead of on every click.

calibrated confidence

stating a level of certainty that matches reality, so "70%" really does come true about 70% of the time.

call / put

the right to buy (call) or to sell (put) at the fixed price.

capstone

the final project of the course: one real problem you scope, build and present end to end.

centroid

the centre point of a cluster, the average of its members.

cherry-picking

showing only the flattering slice of the data and hiding the rest of the context.

churn

a customer leaving or cancelling; the churn rate is the share who leave in a period.

classifier

a model that sorts each case into one of a few categories.

clustering

sorting unlabelled points into groups of similar ones.

coefficient

the fitted number that says how much one input moves the output.

cointegration

two wandering prices whose combined spread stays stable, so the pair is tradeable.

combinatorial explosion

the number of possible choices blowing up as the problem grows.

commit

one save point: a snapshot of the whole project, with a message.

confidence interval

an honest range for a result that came from randomness, reported instead of a single number.

confusion matrix

the table of the four counts: right and wrong, for each class.

constraint

a rule the answer must obey, like a queue length never going below zero.

convex function

a bowl-shaped cost: every chord lies on or above the curve.

convex optimization

finding the lowest point of a bowl-shaped problem, which a computer can always do reliably.

convex set

a shape with no dents: the line between any two inside points stays inside.

covariance

a number saying whether two stocks tend to move up and down together.

covariance matrix (Σ)

the table holding the covariance of every pair of stocks.

cross-validation

try a setting on several train/check splits and average, to choose a knob without touching the test set.

CVaR / Expected Shortfall

the average loss on the worst few percent of days, beyond the VaR.

CVXPY

a Python library where you state an optimisation almost as you write it on paper, and it solves it.

data scientist

someone who turns a company's messy data into a decision, usually with statistics and machine-learning models.

data-snooping

trying many strategies and keeping the best, so the "winner" is mostly luck.

database

software that stores tables safely on a server and answers queries from many people and programs at once.

DataFrame

a table in Python: rows and columns, like a spreadsheet you drive with code.

DBSCAN

a clustering method that groups by crowding, finds any shape, and labels lonely points as noise.

decision boundary

the frontier where the model switches its vote from one class to the other.

decision tree

a model shaped like a flowchart of yes/no questions.

decision variable

one of the quantities you get to choose.

deploy

put your app on the internet at a public link so other people can use it.

deployment (in production)

the stage where a model leaves the notebook and serves real users, where reliability matters more than cleverness.

denormalization

deliberately repeating facts across tables (pre-joining them) so reads run faster; common in analytics dashboards.

dialect

a flavour of SQL such as SQLite, PostgreSQL, MySQL, SQL Server or Oracle: same core language, small differences at the edges.

dictionary (dict)

a lookup table that maps a key to a value.

differencing

replacing each value by its change from the step before, to remove a trend.

discrete-event simulation

a model that jumps along a clock from one event to the next (an arrival, a service finishing).

distribution

the shape of a single column of numbers: where they cluster and how spread out they are.

diversification

spreading money across stocks that don't move together, to lower risk.

DuckDB

a tool that runs SQL straight on a table in Python, no setup.

efficient frontier

the curve of best portfolios: the most return for each level of risk.

ElasticNet

a blend of Ridge and Lasso.

elbow / silhouette

two ways to decide how many groups to use.

epoch

one full pass over the training data during training.

ER diagram

a picture of a database's tables and the keys linking them.

equity curve

the running value of ₹1 put into a strategy over time.

ESG

environmental, social, and governance: using data and models to assess sustainability and climate risk for companies and investors.

euclidean distance

the straight-line distance between two points, the everyday distance you can measure with a ruler; the default distance KNN uses.

executive summary / one-pager

the whole decision on a single page: answer, a little evidence, a caveat, a next step.

facility location

choose which sites to open and who each serves, cheapest overall.

F1 score

a single number that is high only when precision and recall are both high; the harmonic mean of the two, a common way to compare classifiers.

fan chart

a forecast drawn as a widening band (a range of outcomes) rather than a single line.

fat tails

extreme days happen far more often than a plain bell curve would predict.

feasible region

the set of all plans that obey every constraint at once.

feature

An input you feed a model, one of the things you measure about each case. For a flat, its size and its locality are features. Also called an input variable.

feature engineering

building better input columns so a simple model can succeed.

feature importance

how much each input contributed to the model's decisions.

feature scaling

putting every feature on a comparable scale (e.g. with a StandardScaler) so no single large-range column dominates a distance calculation; KNN and SVM need it, logistic regression does not.

fit (a model)

The act of finding the best settings for a model from data. "Fit a line" means find the slope and starting value that match the data best.

for loop

repeat a block of work once for each item in a collection.

foreign key

a column that holds another table's primary key, stitching two tables together.

forward pass

sending an input through the network to get a prediction.

function (in code)

A named, reusable recipe: you give it inputs, it returns an answer. See the Python primer.

global optimum

the genuinely best answer, not just the best nearby.

groupby (split-apply-combine)

split rows into groups, apply a summary to each, combine the answers into a small table.

heuristic

a fast, simple rule that finds a good answer, not always the perfect one.

holding cost / stockout

the cost of stock sitting idle, and of running out.

hypothesis test

the honest procedure for deciding whether a difference is real or just luck.

impurity

a number for how mixed a group of labels is; 0 means all one class.

index

the row labels down the left of a table; the address of each row.

information gain

how much a question lowered the impurity; the tree picks the biggest.

integer programming

optimization where some variables must be whole numbers.

interaction feature

a new column built from two others together (weekend AND rain), carrying signal neither column holds alone.

intercept

The starting value of a straight line, the prediction when the input is zero. In y = slope × x + intercept it is the second number.

join

combining two tables by matching on a shared column (a key).

k-means

a clustering method: pick a number of groups, then move each group's centre to the average of its points, repeating until nothing moves.

Kaggle

a free website where you enter data-science competitions and learn from other people's shared notebooks.

kernel

a trick that lets an SVM bend its boundary into a curve (e.g. the RBF kernel) instead of a straight line, by implicitly measuring similarity in a higher dimension.

k-means

a clustering method: pick a number of groups, then move each group's centre to the average of its points, repeating until nothing moves.

knapsack problem

pick items under a capacity limit to maximise total value.

KNN (k-nearest neighbours)

a classifier that labels a new case by a majority vote of the k stored cases closest to it (by Euclidean distance); it stores the data and does no real training.

Lasso

regularization that pushes some weights to exactly zero, dropping those features for you.

law of large numbers

the average of many random samples settles close to the true value as you take more of them.

lead time

the delay between placing an order and it arriving.

least squares

The rule for picking the best line: choose the line that makes the total of the squared misses as small as possible. See Lines and least squares.

library

A ready-made toolbox of code you import and use instead of writing everything yourself. numpy, pandas and scikit-learn are libraries.

linear program (LP)

a plan where the objective and every rule are plain weighted sums, no squares or curves.

list

an ordered collection of values, written in square brackets.

Little's Law

average number in a system equals arrival rate times the average time each item spends in it.

live demo

running your app in front of people, live, instead of showing a screenshot.

local optimum

a dip that beats its neighbours but is not the overall best; a trap that only wobbly problems have.

log-return

the same day-to-day change written with a logarithm, so the numbers add up nicely over time.

logistic regression

the classic classifier: a linear score squashed into a probability.

long / short

going long is buying now hoping the price rises; going short is selling first (borrowed) hoping to buy back cheaper.

look-ahead bias

accidentally using information you could not have had yet, which flatters a backtest.

loss

one number saying how wrong the current predictions are; smaller is better.

loss distribution

the spread of all the day's outcomes, drawn with bigger losses on the right.

LP relaxation

the easy version with the whole-number rule dropped; its answer can be fractional.

MAE (mean absolute error)

The average size of the model's misses, ignoring whether each miss is above or below. Smaller is better. In the same units as the thing you predict, so it is easy to explain.

Markov chain

a system that hops between states, where the next state depends only on the current one.

matrix

A table of numbers arranged in rows and columns. Useful for holding many features for many cases at once. You can do the whole course without manipulating matrices by hand.

merge (join)

glue two tables together by matching a shared key column.

missing value (NaN)

a blank cell; the honest way to record "we do not know".

ML engineer

someone who makes a working model run reliably for real users at scale, and keeps it healthy over time.

model

A rule that turns inputs into a prediction. A fitted straight line is the simplest model in the course.

Monte Carlo

estimate a quantity by generating many random scenarios and averaging the outcomes.

Monte Carlo simulation

rolling many random possible futures and reading the answer off them.

MSE (mean squared error)

The average of the squared misses. Squaring punishes big misses more than small ones. Smaller is better. Used because it has nice mathematical behaviour.

MSE, MAE, R²

three honest scores for how close the predictions are.

NaN

pandas' marker for a missing or blank value.

neuron

one small step that multiplies inputs by weights, adds them up, and bends the result.

normal equation

The direct formula that gives the best-fit line in one step, without trying many lines. Uses matrices. Optional: the idea of least squares is what matters, the computer applies this for you.

normalization

designing tables so every fact is stored in exactly one place, which prevents contradictory copies.

null hypothesis

the sceptical default: there is no real difference, any gap is chance.

objective

the one quantity you are trying to make best (smallest wait, biggest yield).

one-hot encoding

turning a text category into one 0/1 column per value, so no fake order is implied.

operations research (OR)

using maths and simulation to make operational decisions better: routing vehicles, scheduling staff, setting inventory.

optimization

choosing the best plan a set of limits allows.

option

a contract giving the right, not the duty, to trade at a fixed price.

overfitting

When a model learns the noise in the training data instead of the real trend, so it looks great on data it has seen and does badly on new data. The reason we always test on held-out data.

p-value

if the change did nothing, how often luck alone would give a result this extreme. Small means surprising, so evidence of a real effect.

parameter

a number the world hands you and you hold fixed for one run, like an arrival rate or a cost.

payoff

what the option is worth at expiry, given the final stock price.

PCA

squashing many columns into a few that keep most of the spread, so you can plot or de-noise the data.

penalty / alpha

the size charge added to the loss; alpha sets how strong it is.

Pipeline

one object that does the data-prep and the model together, so the same steps run the same way every time.

portfolio

the public collection of your work (repos, demos) that an employer can look at directly.

portfolio project

one finished project of your own, shared on GitHub, that shows an employer what you can actually do.

practical significance

whether an effect is big enough to be worth acting on, as opposed to merely unlikely to be luck.

precision / recall

of the cases we flagged, how many were real; and of the real ones, how many we caught.

prediction interval

the band around a forecast showing how uncertain it is.

premium

the price the buyer pays up front to own the option.

primary key

the column that uniquely identifies each row of a table, like employee_id.

prime number

a whole number above 1 whose only exact divisors are 1 and itself.

push / pull

send your save points up to GitHub / bring others' back down.

put-call parity

a fixed relationship linking a call, a put, the stock and cash, true with no model at all.

pyramid principle

Barbara Minto's rule: answer on top, grouped support below, detail at the base.

quadratic program (QP)

a bowl-shaped objective with straight-line fences; the SVM is one.

quant

a quantitative analyst who uses maths, statistics and code to price assets, manage risk, or design trading strategies in finance.

quantile

the value a given fraction of the numbers sit below; the 95% quantile has 95% below it.

query

one SQL question, and the smaller table it returns.

random variable

a number whose value is decided by chance, like a dice roll or a customer's waiting time.

referral

someone already inside a company recommending you, which moves your application to the top of the pile.

regularization

a gentle rule that discourages a model from over-trusting any one feature, so it does better on new data.

remote / GitHub

the shared copy of your repo online; GitHub is where it lives.

repository (repo)

the folder Git watches, together with its full history.

representation

the particular way you write the data down; changing it changes what the model can learn.

requirements.txt

the list of exact package versions the hosting machine must install.

residual

The miss for one data point: the real value minus the model's prediction. Least squares makes the squared residuals small. See Lines and least squares.

return

the percent change in price from one day to the next.

Ridge

regularization that shrinks every weight toward zero, but never to exactly zero.

risk (volatility)

how much the returns bounce around; the spread of the returns.

ROC-AUC

one number for how well the model ranks real positives above the rest; 1.0 is perfect, 0.5 is guessing.

R² (R-squared)

A score from 0 to 1 (roughly) saying how much of the variation in the data the model explains. 1 is perfect, 0 is no better than guessing the average.

scope

the exact boundary of what your project will and will not do; to "lock scope" is to fix that boundary so you stop wandering.

seasonality

a pattern that repeats every fixed number of steps.

seed (random seed)

A fixed starting point for the computer's random numbers, set with np.random.seed(0), so that everyone gets the same "random" data and results can be reproduced.

sentinel value

a fake stand-in for missing, like 999 or "NA", that must be unmasked to a real NaN.

serialize (joblib.dump)

write a trained model to a file so it loads later without retraining.

Series

a single column of a DataFrame, carrying its row labels.

service level

the fraction of customer demand you actually meet from stock.

shadow price

how much the best answer moves if you loosen one constraint by one unit.

shape

how big an array is along each direction, like (3, 4) for 3 rows and 4 columns.

share / equity

a share is a tiny slice of ownership of a company; equity is the general word for it.

Sharpe ratio

return above the safe rate, divided by risk; reward per unit of risk.

sigmoid

the S-shaped curve that turns any number into a value between 0 and 1.

simulation

running a model step by step to watch how a system behaves over time.

slope

How steep a straight line is: how much the output goes up for each one-unit increase in the input.

solve a system

give the computer some facts and ask it to find the unknown values that fit.

solver

the tool (here CBC, inside PuLP) that searches for the best plan.

spread

the gap between two prices, A − β·B, which for a good pair stays tethered to a mean.

SQL

a short language for asking a table a precise question.

standardisation (scaling)

shifting and stretching a column so it is centred at 0 with spread about 1, putting all columns on a common footing.

standardise (scaling)

rescale each feature to a comparable footing so the penalty treats them fairly.

state

one of the few situations a system can be in (sunny/rainy, working/broken).

stationary

a series whose statistics stay steady over time, so the past can teach us about the future.

stationary distribution

the steady long-run mix the system settles into.

statistical power

the chance of catching a real effect if one exists; the usual target is 80%.

Streamlit

a library that turns a plain Python script into a web page, with no HTML.

stress test

asking what one specific named disaster (a 2008-style crash) would cost the book today.

strike

the fixed price written into the option, written K.

support vector

a data point sitting right on the edge of an SVM's margin; a handful of these fix the whole boundary.

SVM (support vector machine)

a classifier that places the boundary to leave the widest gap (margin) between the two classes; only the borderline points (support vectors) on the margin's edge decide where it goes.

table (relation)

data as rows and columns; one row is one record.

tail

the far end of the distribution, the rare extreme outcomes.

target

The thing you are trying to predict, the answer column. For house prices, the price is the target. Also called the output or label.

tensor

PyTorch's array of numbers, like a NumPy array that can also track gradients.

test statistic

the effect measured in standard-error units, signal over noise.

the Greeks

how much the option price moves when one input moves (Delta, Gamma, Theta, Vega, Rho).

threshold

the cut-off probability at which we decide to call a case "yes".

time series

a column of numbers recorded in time order, each with a date.

traceback

the block of text Python prints when code breaks; read it bottom-up.

train / test split

Splitting your data into a part to learn from (train) and a part kept hidden to check honestly how well the model does on cases it never saw (test).

transaction cost

what each trade really costs: brokerage, the bid-ask spread, and taxes like STT.

transition matrix

the table of jump chances; each row sums to 1.

trend

a slow drift up or down over time.

truncated axis

a chart whose value axis does not start at zero, which fakes a big change out of a small one.

type

what kind of value something is: a whole number, a decimal, text, or true/false.

utilisation

the fraction of time a server is busy; waits blow up as it nears 100%.

Value at Risk (VaR)

the loss you won't exceed at a chosen confidence over a chosen horizon.

VaR (Value at Risk)

a risk number: the loss a portfolio is not expected to exceed on most days, over a chosen window.

variable (in code)

A name that holds a value so you can reuse it. See the Python primer.

vector / matrix

a list of numbers, and a table of numbers (rows and columns).

virtual environment

a sealed toolbox of libraries just for one project.

volatility

how much the price swings; the size of the moves, ignoring direction.

weight / bias

the dials of the network: the numbers it adjusts while learning.

while loop

repeat a block of work until a condition stops being true.

widget

an on-screen control (a slider, a box, a dropdown) that collects one input.

window function

a calculation that adds a column (like a running total) while keeping every row.

z-score

how many standard deviations a value sits from its mean; it turns the spread into a same-scale signal.
