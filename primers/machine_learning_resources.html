Machine Learning — the best things to watch, play with, and read

This is a curated companion to the machine-learning block (Sessions 7–13). You do not need any of it to finish the labs — the notebooks are self-contained. But the resources below are the ones worth your time when you want a second explanation, a picture that moves, or the deeper maths. We would rather point you at the best explanation in the world than re-record a worse one.

Everything here is free.

Play with it (interactive demos)

Nothing builds intuition faster than dragging a slider and watching the model react.

  • A Neural Network, in your browser — TensorFlow Playground. Add neurons, change the activation, watch the boundary bend. Best paired with Session 13.
  • Gradient descent & loss, live — Google's ML Crash Course: Linear regression playground. Move the line, watch the loss. This is the "Parameters–Loss demo" idea from Sessions 7–8.
  • Principal Component Analysis, visually — Explained Visually: PCA. See what a "principal component" actually is. For Session 11.
  • See k-means run — Visualizing K-Means. Place the centroids yourself and step through the iterations. Session 11.
  • A decision tree, one split at a time — R2D3: A Visual Introduction to Machine Learning. The most beautiful explanation of a decision tree ever made. Session 10.

Watch it (videos)

  • 3Blue1Brown — Neural Networks (playlist). The gold standard. Chapters 1–2 for what a network is, 3–4 for backpropagation and gradient descent. Watch before Session 13; it will make the lab click.
  • 3Blue1Brown — Gradient descent, how neural networks learn (video). The "walking downhill" picture from Session 7, done properly.
  • StatQuest with Josh Starmer — search his channel for any algorithm you meet: Logistic Regression, Decision Trees, Random Forests, Gradient Boosting, SVMs, PCA, ROC & AUC. Cheerful, slow, and correct. Great for Sessions 9–11.
  • StatQuest — Support Vector Machines (video). Margins and the kernel trick, gently.

Go deeper on the maths (optional)

For the maths-comfortable who want the rigour behind the pictures.

  • Mathematics for Machine Learning — the Imperial College / Coursera specialization (site); the free book covers the linear algebra, calculus, and probability the whole module rests on. This is the "where does the maths live" answer.
  • 3Blue1Brown — Essence of Linear Algebra and Essence of Calculus (playlists on YouTube). Vectors, matrices, eigenvectors, derivatives — the visual foundation for PCA, regression, and backprop.
  • An Introduction to Statistical Learning (ISLR) — free PDF. The friendliest serious ML textbook. Chapters 3 (regression), 4 (classification), 8 (trees) map straight onto Sessions 7–10.

Reference (keep a tab open)

  • Google Machine Learning Crash Course — https://developers.google.com/machine-learning/crash-course. Short, excellent, and the source of much of our evaluation vocabulary.
  • scikit-learn User Guide — https://scikit-learn.org/stable/user_guide.html. Every model we use, with examples. The algorithm cheat-sheet map answers "which estimator should I try?".
  • Andrew Ng — Machine Learning Specialization (Coursera). The classic gentle on-ramp if you want a full second course.
  • The course's own cheat sheets — Python, NumPy, pandas, and scikit-learn/ML are on the Start here page. Print the scikit-learn one and keep it next to you during the labs.

Data to practise on

  • Kaggle Datasets — https://www.kaggle.com/datasets (and Kaggle competitions for a challenge).
  • UCI Machine Learning Repository — https://archive.ics.uci.edu/.
  • Hugging Face Datasets — https://huggingface.co/datasets.
  • Indian data: AI4Bharat, the government AIKosh, and data.gov.in. Good for a capstone with local relevance.

Where to run code

  • Google Colab — https://colab.research.google.com. Every notebook in this course opens here with one click; nothing to install. This is all you need.
  • Kaggle Notebooks — free GPUs if a later project wants one.
