Python in 15 minutes

This is everything you need to start the course if you have never coded. You do not need to memorise it. You need to have seen it once, so the notebooks feel familiar. Open a notebook (on Google Colab, no install needed) and type each example yourself. Press the play button and watch what happens.

Running code in a notebook

A notebook is a page made of cells. A cell holds a few lines of code. You press the play button (or Shift+Enter) and the computer runs that cell and shows the result just below it. You go cell by cell, top to bottom. That is the whole rhythm of this course.

A variable is a labelled box

A variable is just a name that holds a value, so you can use it again later.

price = 250
quantity = 3
total = price * quantity
print(total)      # shows 750

print(...) tells the computer to show you something. Use it often so you can see what is happening.

The everyday types of value

  • a whole number: 5
  • a decimal number: 4.5
  • text, in quotes: "Pune"
  • true or false: True, False
  • a list, several things in order, in square brackets: [10, 20, 30]
city = "Pune"
temperatures = [31, 33, 30, 29]
print(city)
print(temperatures)

A list holds many values

prices = [100, 250, 90, 400]
print(prices[0])      # the first one: 100   (counting starts at 0)
print(len(prices))    # how many: 4

A loop repeats something

Say you want to add up all the prices. A loop walks through the list one item at a time.

prices = [100, 250, 90, 400]
running_total = 0
for one_price in prices:
    running_total = running_total + one_price
print(running_total)     # 840

The indentation (the spaces at the start of the line) matters in Python. The indented line is the thing that gets repeated.

An if makes a decision

score = 72
if score >= 50:
    print("pass")
else:
    print("try again")

A function is a reusable recipe

You give it some input, it gives you back an answer. You define it once and use it many times.

def add_gst(amount):
    # add 18 percent GST to a price
    return amount * 1.18

print(add_gst(1000))     # 1180.0
print(add_gst(250))      # 295.0

Libraries do the heavy lifting

You rarely write everything yourself. You import a library, a ready-made toolbox, and use its tools. In this course two show up constantly:

import numpy as np                 # fast maths on lists of numbers
import matplotlib.pyplot as plt    # drawing charts

numbers = np.array([10, 20, 30, 40])
print(numbers.mean())              # the average: 25.0

plt.plot(numbers)                  # draw them
plt.show()

np and plt are just short nicknames people always use for these two.
